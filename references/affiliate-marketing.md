# 联盟营销：招募量不是成绩，激活率才是

> 历史样本（2019 年跨平台数据，**不是行业基准**）：登记联盟客 6,104 个 → 有流量 987 个（16.2%）→ 有销量 323 个（5.29%）。
> 它只说明一件事：**批准很多人 ≠ 有人真正贡献销售。** 联盟项目的成绩在激活，不在名单长度。

## 一、漏斗八阶段（周报口径）

```
已邀请 → 已回复 → 已加入 → 已拿到素材 → 已上线推广 → 有效点击 → 有效订单 → 带来新增客户
```

每个阶段都能找到下一个改进动作；月报如果只写"新招募 300 个 Publisher"，管理层会被虚假繁荣误导。

## 二、招募前：按类型分层，不按名单长度

| 类型 | 特点 | 动作 |
|---|---|---|
| **内容型**（测评博客、YouTube、专业媒体、对比站、邮件通讯） | 需要样机、素材、长准备期；内容长期留存 | 优先投入，给差异化佣金与内容支持 |
| 优惠券/返利型 | 接近购买环节，易截流 | 单独规则，严控品牌词与叠加 |
| 社交型（创作者、论坛、社群） | 场景匹配度高 | 按人群匹配筛选 |
| 工具/聚合型 | 覆盖量大，增量存疑 | 严查推广位置与真实增量 |

优先级永远放在**产品匹配度与内容价值**上，不放在平台推荐的注册数量上。做储能找露营/应急/太阳能媒体；做专业设备找真正理解场景的人。

## 三、平台与计划资料（先于开发信）

平台选择（Impact / Awin / CJ 等）确认准入、合同、结算、技术对接后，先写计划资料：

- 英文品牌介绍、目标市场、允许流量类型
- **佣金比例、Cookie 时长、订单锁定期**
- 退款与取消订单处理、支付条件
- **品牌词竞价政策、优惠码规则**
- 反作弊条款、数据与证据要求、联系人

上线前测试闭环：点击 → 下单 → 退款 → 佣金事件，确认归因规则与 Shopify 订单可对账。

## 四、Publisher Kit（批准后立刻发）

品牌介绍、核心 SKU、目标地区、可用素材、默认落地页、最新价格、佣金、Cookie、退货处理、品牌词政策、禁止流量类型、联系人。

产品 Feed 至少含：商品 ID、标题、描述、价格、库存、图片 URL、落地页 URL、币种、类别、更新时间——**避免联盟客推广已缺货或价格错误的产品**。

## 五、激活五节点（比继续招募重要）

| 节点 | 检查 | 卡住时的动作 |
|---|---|---|
| 批准后 7 天 | 是否领取资料 | 补素材/答疑，不催 |
| 首条内容/推广位 | 是否上线 | 提供选题与素材支持 |
| 首次有效点击 | 流量是否进来 | 优化推广位置与落地页 |
| 首次有效净订单 | 是否成交 | 查流量匹配与页面，不先查人 |
| 持续贡献 | 连续净贡献 | 阶梯佣金、独家折扣、新品优先 |

30 天没有动作：**询问障碍**（缺图？缺规格？缺样机？），不是直接责怪对方。激活节奏：加入当天欢迎资料 → 一周后按类型发选题 → 新品/促销给实用素材 → 30 天问障碍。

## 六、佣金：不一刀切，归因 ≠ 利润

- 内容型媒体承担研究与制作成本，给更有吸引力的佣金或支持；优惠券/返利/媒体采买按增量价值单独评估；
- **佣金归因不是利润贡献**：用户被广告和红人种草、结账前搜"品牌名 coupon"、从返利站完成购买——平台给返利站记功，但这笔订单是否新增，不能只靠归因窗口判断；
- 建立订单级机制：**订单去重、优惠码流向、New-to-Brand 比例、品牌词竞价检查、异常点击识别**；
- 两个极端都错：放任 Coupon 站截流 / 一概否认所有优惠券联盟客的价值（部分区域导购平台确有真实拉新能力）；
- 目标不是把销售额从 Google 报表挪到 Impact 报表，是**新增有效需求并守住贡献利润**。

## 七、违规监控：证据先行，不凭猜测

每周核查：异常品牌词广告、未授权优惠码、虚假内容、异常跳转、点击到订单比例异常。

**正确处理流程**：保存证据（搜索结果、时间、地区、广告链接、联盟 ID、订单）→ 要求对方提供推广页面、投放位置、实际渠道、时间范围与点击路径 → 依据计划条款暂停待审、处理无效转化 → 全程留痕。

**禁止**：仅凭"没在对方网站看到推广"就指控作弊、直接抹掉所有订单。规则对所有联盟客一致、事先公开。

## 八、周报口径（与周经营看板合并）

批准数、内容上线数、有效点击联盟客数、有净销售联盟客数、退款率、佣金率、可疑订单调查进度——**最后一行和第一行同样重要**。

## 九、过关标准

- 计划资料与佣金政策先于第一批邀请发出；
- 漏斗八阶段有数据，周报看激活率不看批准数；
- 建立订单级去重与 New-to-Brand 口径，联盟报表不与广告报表简单相加。
