# 品类适配器：礼物 / 创意家居（基准品类）

> 这是本 playbook 的**基准品类**——所有通用 references 的参数默认按此品类设定。其他品类适配时，对照本文件找差异。

## 品类结构特征

| 维度 | 基准设定 |
|---|---|
| 客单价 | ≈ $100（$50–$150 区间） |
| 决策周期 | 天–周（场景触发 + 冲动混合） |
| 购买动机 | 情感、场景时效（节日/生日/乔迁）、"送得出手" |
| VOC 主来源 | Amazon 评论、Google 搜索词、竞品评论区 |
| 第一渠道 | Google 搜索（交易词 + 场景词） |
| 内容形态 | 场景图、送礼指南、"适合送谁" |
| 复购结构 | 一次性为主，复购稀疏 |
| 认证门槛 | 低–中（普通消费品） |
| 售后 | 退货退款为主 |
| 现金流 | 先花钱后收钱（广告即时付、回款 30–60 天） |
| 季节性 | 极强，Q4 占全年大头 |

## 关键阈值（本品类专用，换品类必须重算）

- 尾程物流占售价：**> 15% 即结构性伤害**，> 18% 考虑换品类；
- 退货准备：按 5–8% 货值预估，**退货集中在节后**；
- ROAS 红线：2.0–2.5 是常见生死线（取决于上述成本结构，**必须用自己的表算**）；
- 库存：轻库存快周转起步，但意味着**无供应链壁垒**——这是基准品类最大的结构性软肋（详见案例研究）。

## 本品类特有的四个坑

1. **季节性误判**：把 Q4 峰值当年均需求，按峰值备货 → 节后压死现金流；
2. **体积重量忽视**：送礼件往往"轻但占地方"，体积重击穿尾程；
3. **节后退货潮**：12 月底–1 月的退货和客服洪峰，备货和排班没有按此设计；
4. **一次性消费幻觉**：把礼物用户当作品牌用户经营 EDM/会员，投入产出极低——要么接受一次性，要么用耗材/配件/节日周期改造复购。

## 换品类适配时，对照本文件逐行回答

1. 客单价量级变了吗？（→ 重算 CPA 容忍度和渠道）
2. 决策周期变了吗？（→ 重调归因窗口和内容深度）
3. 复购结构变了吗？（→ 重调 LTV 模型和 EDM 权重）
4. 认证门槛变了吗？（→ 重写上线前核查清单）
5. VOC 来源变了吗？（→ 重定证据采集渠道）
6. 第一渠道变了吗？（→ 重排冷启动顺序）
7. 售后复杂度变了吗？（→ 重设 SOP 和组织形态）

七问的答案，就是新适配器要写的全部内容。
