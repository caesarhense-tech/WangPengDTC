# 品类适配器：机器人 / 3D 打印机 / 智能硬件

> 与"礼物/家居基准"的结构差异：**礼物卖场景和冲动，硬件卖参数和信任。** 前端从"承接搜索"变成"经营社区和内容"，后端从"退货处理"变成"维修和备件体系"。
> 通用纪律（十条核心纪律、单位经济公式、0→1 五条件、信号复盘法）全部适用，本文件只写**差异与新增**。

## 一、认证与合规核查（上线前的一票否决）

硬件的合规链比一般消费品长，且**核验不通过不得上线**——营销排期不是理由。

| 认证/项 | 适用 | 需要核验的文件 |
|---|---|---|
| FCC（美国 EMC） | 所有带电/无线产品 | 测试报告 + 符合性声明（DoC），核对型号与报告编号 |
| CE（欧盟 EMC/LVD/MD/RoHS） | 欧盟销售 | 技术文件 + DoC + 授权代表（如适用） |
| UKCA | 英国 | 同 CE 口径 |
| 激光安全（IEC 60825-1 / FDA Laser） | 激光雕刻机、光固化打印 | 等级标注（Class 1 为消费级目标）、互锁、警示标识 |
| 机械安全（EN ISO 12100 风险评估） | 有运动部件的设备 | 风险评估文档、防护设计说明 |
| 电池（UN38.3 + MSDS） | 含锂电池产品 | 运输鉴定报告、运输合规文件 |
| 包装运输（ISTA） | 大件/易损/高货值 | 跌落振动测试报告 |
| 产品责任险 | 强烈建议 | 保单（硬件品类基本必需） |

**纪律**：
- 供应商证书必须**核对到型号与报告编号**；同系列某型号通过 ≠ 全 SKU 满足；
- 不得把供应商宣传页的认证 Logo 直接复制到网站；
- 激光、高温、运动部件相关的安全声明，必须有对应测试证据；
- 每项认证记录：文件链接、核验人、日期、状态、**阻断条件**。核心认证未过 = 不得发货、不得投广告。

## 二、参数型产品页结构

硬件买家的第一个动作是翻参数、找测试条件、找"不能做什么"。页面按这个顺序组织：

```
1. 首屏：产品是什么 + 3 个核心参数 + 适用边界（能做什么/不能做什么）
2. 完整规格表：可复制、带单位、注明测试条件与标准
3. 可复核对比：与上一代/竞品/自家其他型号（同条件对比）
4. 真实测试证据：视频、数据曲线、拆解图
5. Troubleshooting 前置：最常见的 5 个问题及处理
6. 保修与备件政策 + 固件支持说明
7. 社区入口（论坛/Discord/用户群）
```

**纪律**：
- 参数必须**可复核**：注明测试条件、标准、样本。"精度 0.01mm"不讲材料和速度条件 = 虚假宣传；
- **"能/不能"边界声明比卖点更重要**——硬件退货第一原因是预期不符，不是质量；
- 把 troubleshooting 从售后提到售前：买前教会用户排查，买后省掉一半工单；
- 参数按用户决策顺序组织，不堆成工程数据库。

## 三、技术 SEO / GEO（硬件品类的天然优势）

关键词四篮框架不变，但**权重重新分配**：问题词与 troubleshooting 词成为主体。

| 词类 | 硬件示例 | 权重变化 |
|---|---|---|
| 交易词 | "best 3d printer under $500" | 中（客单高、要比较） |
| 比较词 | "ender 3 vs bambu a1" | 高（研究型购买必看） |
| **问题词** | "how to fix layer adhesion" / "not extruding" | **最高——硬件搜索的主体** |
| 品牌/固件词 | "xxx firmware update log" | 高（存量用户高频回访） |

**内容四组（按优先级）**：
1. 使用教程与 troubleshooting（首选）：真实固件版本、注明日期，**过时教程是差评和退货来源**；
2. 产品证据：测试方法、拆解、长期使用报告（硬件买家信任"跑了 1000 小时后"的内容）；
3. 购买比较：敢写"适合谁/不适合谁"；
4. 品牌信任：固件更新历史、开源姿态、保修案例、安全记录。

**GEO**：AI 搜索高频问"$500 预算帮我选台 3D 打印机"——结构化参数表、稳定 URL、固件更新日志是最容易被引用的内容源。监测问题库示例：
- "best beginner 3d printer 2026"
- "can a $300 printer print abs"
- "which resin printer has the easiest calibration"
- "how loud is a 3d printer in an apartment"

**纪律**：GEO 不是新渠道预算，是产品参数、教程、测评、口碑的延伸；先消除官网与第三方信息的参数冲突，再谈被 AI 引用。

## 四、社区渠道纪律（Reddit / Discord / 论坛）

硬社区（r/3Dprinting、r/robotics、Discord、厂商论坛）是硬件品牌的命脉，也是坟场——**规则是"先贡献再曝光"**。

- 每个社区有自己的 self-promotion 规则（比例限制、专门的活动帖位），**发帖前先读规则**；
- 官方账号以"技术支持 + 透明沟通"存在：回答问题、公开缺陷、承认问题并给出修复时间表；
- 鼓励 UGC：模型/作品分享、打印成功展示、用户教程——社区内容是最强的第三方证据；
- 社区高频问题**回流**到产品页 FAQ 和教程（VOC 闭环）；
- KOL 选择看"能不能讲清技术细节"，不看粉丝量。

**红线（一次违规毁掉品牌）**：不买水军、不操纵投票、不删差评、不马甲发软文。硬社区的扒皮能力极强，被识别的代价是长期的。

**衡量**：不是发帖数，是①非官方渠道的主动讨论量 ②社区问题被解决率 ③社区内容进入 Google/YouTube 搜索结果的数量。

## 五、YouTube 测评合作（硬件品类权重最高的渠道）

硬件测评视频活在 Google/YouTube 搜索结果里**数年**，长尾价值远超其他品类——**授权条款比一次佣金重要**。

**Brief 在通用版基础上加硬件专项**：
- 安全操作边界：激光防护、高温部件、运动机构——不得为拍摄效果展示危险操作；
- 不得演示超出额定规格的用法（如超额定电压、禁用材料）；
- 测试条件要求：注明材料/速度/环境/固件版本，否则数据不可比；
- 必须包含：开箱、首次 setup 体验（新手视角最宝贵）、真实使用 30 天以上、缺点与限制。

**分层选择**：
- 头部（声量）：首发造势用；
- **中腰部技术向（信任）**：能讲清参数边界和缺陷，是决策链核心；
- 长尾教程向： troubleshooting 内容，SEO/GEO 的引用源。

**合作形式**：样机送测（默认）、固定费用 + 联盟佣金（带货向）、长期 Ambassador（旗舰产品线）。硬件送测成本高，发货前确认对方有完成真实测试的条件（耗材、时间、环境、技能）——**给了样机不等于得到有价值测评**。

## 六、众筹 / 预售现金流模型（先收钱后交付）

Kickstarter/Indiegogo 对硬件是天然主场，但**现金流方向与常规独立站完全相反**：Campaign 期收钱，交付在生产后 3–9 个月。

**三大死因**：
1. **交付延期**（第一死因）：烧掉信任和现金流，退款和差评在延期中爆发；
2. **低估总成本**：BOM + 头程 + 关税 + 包装 + 退换准备 + 平台费用，低估 20% 是常态；
3. **售后无准备**：第一批用户是早期采用者，容忍缺陷但不容忍无回应。

**纪律**：
- 交付时间承诺加缓冲：内部估算 × 1.5 起步，页面写"预计交付"不写"保证交付"；
- 预留 15–20% 现金应对生产和物流超支；
- 放量前先小批量 PGF（pre-production feedback）验证产线；
- 更新节奏透明：生产延期就主动说明新时间表和原因，沉默是二次伤害；
- **众筹验证的是需求，不是交付能力——两件事分开评估**。真金白银的预售是最强的需求信号，但产线、认证、备货是另一张考卷。

## 七、耗材 LTV 模型（利润核心）

主机可以微利，**耗材和配件才是长期利润**——利润表必须双线核算：

| 线 | 逻辑 | 容忍度 |
|---|---|---|
| 主机线 | 获客逻辑 | 可接受低贡献甚至战略亏损 |
| 耗材线 | 利润逻辑 | LTV 决定品牌价值 |

**关键指标**：耗材复购率、活跃设备数（月活设备）、单机年耗材消耗额、耗材毛利占比。

**最大风险：被通用耗材平替**（参考喷墨行业"墨盒模式"的反面）。应对：官方耗材的品质一致性（打印失败一张的钱够买一卷差距）、Auto-ship 订阅（独立站相对 Amazon 的结构性优势）、固件层面的材料优化（透明、可关闭、不锁死——锁耗材在硬社区是自杀行为）。

## 八、售后 SOP（品牌资产，不是成本中心）

硬件售后三件套：

1. **RMA 流程**：时效承诺（如 48 小时响应）+ 预付/到付标签 + 换修二选一说明；**时效承诺写进产品页**——这是硬件的信任组件；
2. **备件计划**：易损件分类（喷嘴/热床/皮带/滤网/电机）、自营备件商店、常见故障自助更换指南；
3. **固件支持**：公开更新日志（修了什么、已知问题）、支持回退版本、已知问题清单（Known Issues）。

**指标**：一次解决率、备件发货时效、RMA 周期、NPS、社区问题解决率。

**社区互助**：老用户是最强的支持力量——公开感谢、给测试资格、积分体系，把售后从成本中心变成社区运营中心。
