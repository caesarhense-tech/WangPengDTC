# 单位经济模型：先算账，再开工

> 第一张表不是选品表，是利润表。算不清一单剩多少钱，不开工。

## 一、核心公式

```
广告前贡献 = 售价 − 采购成本 − 头程/尾程物流 − 支付手续费 − 退货准备 − 售后准备
广告后贡献 = 广告前贡献 − 单均广告费（= 客单价 ÷ ROAS）
```

**只认"广告后贡献"，不认前台 ROAS。** ROAS 是分母游戏，贡献才是真相。

## 二、教学演算示例（$100 客单，礼物/家居类）

| 项目 | 金额 | 说明 |
|---|---|---|
| 售价 | $100 | |
| 采购成本 | ≈ $28 | 含质量损耗 |
| 尾程物流 + 仓储 | ≈ $16 | **软肋高发区，占比 15%+ 就要警惕** |
| 支付手续费 | ≈ $3 | 按实际费率 |
| 退货/售后准备 | ≈ $6 | 节庆品类退货集中在节后 |
| **广告前贡献** | **≈ $47** | |
| 广告费（ROAS 2.3 口径） | ≈ $43.5 | 100 ÷ 2.3 |
| **广告后贡献** | **≈ $3.5** | 一单真正剩下的 |

**这个例子的教学意义**：ROAS 2.3 是"能支撑广告费"的，但一单只剩三四美元——模型转得动，转不出利润。同样的 ROAS，在不同成本结构下是不同的生意。

## 三、三个必须写进预算审批单的数字

1. **单笔订单贡献额**：收入减产品、物流、支付、售后、折扣、渠道可变成本。
2. **允许 CPA**：在目标贡献利润约束下，能拿出多少钱买一个客户。CPA 红线 = 广告前贡献 − 目标留存。
3. **现金回收周期**：从付广告费、备库存到最终回款要多久。**高客单价产品 ROAS 好看，但账期长、售后重、样机贵，规模化反而拉紧现金流。**

## 四、倒推所需 CVR

```
允许 CPA ÷ 假设 CPC = 所需转化率（CVR）
```

例：允许 CPA ≈ $98，CPC $2 → CVR 至少 ≈ 2%。如果品类基准 CVR 只有 0.8%，问题未必在投手，在**售价与市场的匹配度**——要么提价、要么降获客成本、要么换品。

## 五、红线与停止规则（提前写死，情绪不碰后台）

| 信号 | 动作 |
|---|---|
| 特定词组累计花费明显超出容忍 CPA，且无可靠加购/结账信号 | 暂停该组，复核词与页面匹配 |
| 有加购但无成交 | 先查运费、支付、SKU、页面，不先动出价 |
| ROAS 好看但扣完退货与履约亏钱 | 按亏损处理，回到承诺与产品一致性 |
| 扩量后边际 CPA 劣化超过阈值 | 停止扩档，回上一档排查 |
| 所有渠道同时无有效信号 | 停止投放，回到需求、价格、产品适配 |

**判断纪律**：不要 100 次点击没订单就判渠道死刑（CVR 2% 时期望值只有 2 单，随机波动极大）；也不要一个侥幸赚钱的订单就放量。是否暂停要结合销量样本、决策周期和订单利润，不套用全行业统一阈值。

## 六、现金流倒挂（比利润先死的环节）

广告费是**即时现金支出**，回款在订单完成后（跨境通常 30–60 天含在途与结算）；节庆品类备货是**提前垫款**。单量越冲，现金越紧。

每月画一张现金曲线，标出三个点：广告支出峰值、备货支出峰值、回款低谷。**最紧的那个月，就是你这个模型能承受的单量上限。** 超过它，利润表再好看也会断。

## 七、周更机制

- 每周用**真实退款、物流和客服成本**更新利润表——不要用月初的假设数字做整月决策。
- 口径统一：Shopify 管收入与退款，广告平台管优化归因，GA4 管行为诊断，财务表管利润。**各平台归因订单不能相加**，同一笔订单会被三个后台同时认领。
- 分 SKU、分渠道、分新老客看贡献利润，不看合并 ROAS。
