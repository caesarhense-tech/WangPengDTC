# Google Ads 打法：一条渠道打穿

> 第一笔预算不是买增长，是买证据。账户最大的产出不是订单，是可解释的证据：哪些词能赚钱、哪些页面能承接、什么价格带承受什么 CPC。

## 一、什么时候优先 Google

| 品类特征 | 优先渠道 |
|---|---|
| 高客单、问题解决型、购买前要比较（家居、工具、设备、专业品类） | **Google 搜索** |
| 视觉驱动、冲动消费、新品需要教育市场 | 先测 Meta/信息流素材 |
| 完全新物种（用户不知道搜什么词） | 只靠 Search 打不开，需内容/达人先教育 |

**小团队隐性优势**：搜索广告素材压力小（文案匹配意图即可），不需要持续供信息流素材——1–3 人团队最供不起的就是素材产能。

## 二、账户结构哲学

- **不为"精细"而过度拆分**：少量意图紧密的广告组，保证每组有足够数据变可解释；几十个饿死的组比三个能学的组贵得多。
- **冷启动三档爬坡**：核心人群词 → 场景词 → 比较词。每档 CPA 可控再开下一档。
- **一个意图对一个落地页**：不要把搜索"适合露营的礼物"的用户导到首页。
- 品牌词与非品牌词分开分析，避免品牌搜索掩盖真实拉新成本。
- 否定词清单每周维护（与购买无关的搜索持续剔除，但别误伤有商业价值的需求）。

## 三、周节奏（账户的日常作业）

| 频率 | 动作 |
|---|---|
| 每日 | 搜索词报告：无关词当天加否定，新出现的有效词当天记录 |
| 每日 | 点击 → 落地页到达 → 加购 → 结账的漏斗有无断裂 |
| 每周 | 按人群/设备/地区/页面核对 CPA 与广告后贡献 |
| 每周 | 用真实退款、物流、客服成本更新利润表 |
| 每月 | 素材/文案版本记录，确认增长来自哪个变量 |

**搜索词报告是日常，不是月报。** 这是本 playbook 里最便宜也最值钱的一条纪律。

## 四、数据症状倒推表（先诊断，再动手）

| 症状 | 优先排查 | 下一轮动作 |
|---|---|---|
| 展示低 | 资格、出价、相关性 | 调整覆盖与素材 |
| 点击高、落地页浏览低 | 加载速度、跳转、误点、设备 | 修页面技术问题 |
| 浏览高、加购低 | 价格、卖点、可信度、流量精准度 | 换首屏主张与证据 |
| 加购高、支付低 | 运费、支付方式、税费、信任 | 亲自走一遍真实结账 |
| CPA 低但退款高 | 承诺超出产品能力 | 改广告承诺与产品说明 |

**纪律**：每次优化只设一个主要假设，记录改版前后数据。冷启动期数据小，经不起同时改标题、价格、图片、按钮、配送政策——先按严重程度修：支付失败、库存错误、运费突变、加载异常是 P0；信息不清、社交证据缺失是 P1；按钮颜色是 P2。

## 五、节庆品类的提前量

礼物流量 Q4 集中爆发。提前一个月就位：账户结构、预算分配、承接页面、库存深度、客服排班。**临阵换页面 = 扔掉积累的数据。**

## 六、扩档纪律

- 每次加预算的前提：上一档的边际 CPA 没有劣化；
- 扩档时同步检查：库存深度、物流时效、客服承接能力——不只看广告后台；
- 扩量后每周问三句：新增订单是新客还是老客？贡献利润有没有下降？库存和客服能不能承受下一波？

## 七、归并对账（避免自欺）

- 同一笔订单可能被 Google、Meta、联盟三个后台同时认领——**各平台归因订单不能相加**；
- 经营口径：Shopify 管收入与退款，广告平台管优化归因，GA4 管行为诊断，财务表管利润；
- 每周保留一个"人工复核样本池"：挑 10–20 个代表订单，把用户路径查清楚（看了什么内容、搜了什么词、用了什么码），比机械追求单一后台 ROAS 有用。
