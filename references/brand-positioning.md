# 品牌定位：一句话讲清楚你是谁

> 定位至少要回答五件事：服务谁；在什么场景；解决什么具体问题；凭什么比替代方案好；哪些事情明确不承诺。
> 定位不是把话说大，而是把重要的话说清楚。

## 一、一句话模板（可直接填空）

> 为【目标人群】在【具体场景】提供【核心结果】的【产品类别】，相比【主要替代方案】，我们的区别是【可证明差异】，**但不适用于【真实限制】**。

三个教学示例（均为演示，非真实品牌）：

- 储能品类：为经常周末露营的美国人，在离网用电场景提供"能带得动关键设备"的便携电源；相比同容量竞品，我们的区别是每台设备都有公开测试条件，但我们不支持持续 800W 以上的大功率家电。
- 礼物品类：为不知道送什么的人，在节日/生日场景提供"送得出手、不会出错"的创意家居；相比 Amazon 杂货铺，我们的区别是每件产品都有真实使用场景图和送礼话术，但我们是小品牌，不承诺全网最低价。
- 硬件品类：为入门创客，在家庭打印场景提供"开箱即能打出可用件"的 3D 打印机；相比同价位机型，我们的区别是调平流程经过 50 人新手测试，但我们在 ABS 等高温材料上不做优化。

注意三个共同点：**人群具体、场景具体、有"不承诺"的半句**。没有后半句的定位，退货和差评会替你补上。

## 二、定位五问（写不出来就不开工）

| 问题 | 反面教材 | 合格答案的特征 |
|---|---|---|
| 服务谁？ | "25–45 岁男性" | 有触发事件的人群（"下周要参加乔迁派对的人"） |
| 什么场景？ | "日常生活" | 可观察的使用时刻 |
| 解决什么具体问题？ | "提升生活品质" | 用户原话级别（"不知道送什么才不会踩雷"） |
| 凭什么比替代方案好？ | "质量更好" | **可证明**的差异（公开测试、新手友好流程、场景内容） |
| 哪些明确不承诺？ | （跳过这问） | 主动写出的限制（"不适合 X"） |

## 三、从定位到落地的一致性检查

定位写完之后，用同一句话检查所有对外触点——**任何一处和定位不一致，改的是那一处，不是定位**：

| 触点 | 检查 |
|---|---|
| 首页首屏 | 前三句能否让人复述出"这是什么、适合谁、凭什么信我" |
| 产品页 | 卖点顺序是否按目标人群的决策顺序（而非工程参数顺序） |
| 广告文案 | 主张是否落在"可证明差异"上，还是空喊形容词 |
| PR 角度 | 编辑关心的"读者价值"是否与定位一致 |
| 内容主题 | 教程/清单类内容是否服务同一人群的同一场景 |
| 客服 FAQ | 高频问题是否暴露了定位没有覆盖的疑虑（→ 回改定位或页面） |

**验收标准**：把一个完全不认识的同事拉到首页，30 秒后他能用自己的话说出"这是给谁的、凭什么信你、哪里不如别家"——三句都能说，定位落地了；只能说第一句，是自嗨。

## 四、定位的两种死法

1. **无限放大**："适合所有人"= 不适合任何人；"全网最好"= 不可证伪 = 不可信。定位的价值在**被证伪的能力**——你敢说"不适合 X"，别人才敢信"适合 Y"。
2. **工厂式定位**："我们质量很好、价格也不错"——这是供应商思维，不是品牌思维。客户不为"很好"付钱，为"具体场景下的具体结果"付钱。

## 五、定位与差异化卖点的关系

差异化不来自"人无我有"，常常来自**同样的东西讲得不一样**：三小时竞品拆解后你会发现，参数相近的产品，有的卖省心安装、有的卖设计感、有的卖专业可靠、有的卖售后承诺——**差异化从"用户最在意的那一两个差异点被讲清楚"里来**，不从产品参数表里来。

定位一旦定稿，写入项目的一页纸业务边界（见 SKILL.md 阶段 0），之后所有渠道动作对照它。
