# EDM 用户资产：把流量变成关系

> 问题不在邮件工具，在团队根本没有设计用户关系。冷启动先做三条自动化（欢迎/弃购/购买后），比买一套复杂营销软件更重要。
> 铁律：**弃购邮件先解释疑虑，再谈优惠**——一上来发折扣，训练的是用户等优惠。

## 一、先分清六种邮件

| 邮件 | 任务 | 优先级 |
|---|---|---|
| 欢迎流程 | 让用户知道品牌是谁、产品适合谁、为什么可信 | ⭐ 冷启动必做 |
| 浏览/加购提醒 | 帮助用户继续决策（遵守订阅与隐私授权） | ⭐ 冷启动必做 |
| **弃结账** | 解释运费、兼容、咨询等障碍，而不是发折扣 | ⭐ 冷启动必做 |
| 购买后 | 订单确认、使用指南、兼容安全、评价请求、配件建议 | ⭐ 冷启动必做 |
| 长期关系 | 真实案例、维护技巧、新品、会员权益 | 有量后做 |
| 复购/升级 | 按产品使用周期触发 | 有复购结构再做 |

## 二、欢迎流程三封结构

```
第一封：品牌是谁 + 主推使用场景（定位的那句话）
第二封：购买前最常见的疑虑（技术参数、兼容、运输、售后）
第三封：真实测评证据 + 售后保障 + 合适的购买入口
```

- 每封只解决一个问题，不要塞满；
- 第二封的内容直接来自 VOC 证据表（用户原话 → FAQ），不要拍脑袋写；
- 触发条件：新订阅未购买；已购买用户自动排除，不要给新客户发"你忘了结账"。

## 三、弃购流程（最容易被做坏的一条）

```
提醒商品 → 解释常见疑虑 → 提供人工客服帮助
         ↓
    （最后才考虑）优惠——且仅对价格疑虑明确的群体
```

**纪律**：
- **不要所有弃购都自动发折扣**——用户会被训练成"加购等邮件"；
- 先查事件触发：是否已购买、是否已退订、是否重复发送；
- 高客单价/长决策周期的品类，弃购邮件的第一价值是"解答疑虑"，不是"催促下单"。

## 四、购买后流程（耐用品尤其重要）

订单确认 → 发货通知（含运输注意事项）→ 首次使用指南 → 设备兼容与安全提醒 → 评价请求 → 适配配件建议。

- 高客单/复杂产品：使用指南做成分步图文或短视频，**买后第一周的体验决定 NPS 和差评率**；
- 评价请求的时机：确认用户完成首次使用后，不要签收当天；
- 配件建议：基于购买品类的自然搭配，不做硬推销。

## 五、指标：不看打开率，看经营影响

| 别看 | 要看 |
|---|---|
| 打开率（受隐私保护和客户端影响，不可靠） | 可送达率、退订率、投诉率 |
| 发送量 | 点击后的站点行为（进站后买了什么） |
| 单封表现 | **不同客户分组的净收入** |
| — | 复购间隔、每封邮件增加的客服负担、实际毛利 |

**自动流程上线后，每月至少检查一次**：链接是否还有效、折扣码是否过期、库存是否变价——不要让一个过期的优惠在系统里跑半年。

## 六、复购设计：按产品的真实周期来

| 产品类型 | EDM 节奏 | 内容 |
|---|---|---|
| 耐用品（一年不复购主机） | 按使用周期触发（首次使用/保养/换季） | 维护技巧、耗材提醒、以旧换新 |
| 耗材型（3D 打印、滤芯等） | 按消耗周期触发 + Auto-ship 订阅 | 补货提醒、用法进阶 |
| 一次性（礼物） | 按节日周期触发（节前 4–6 周） | 送礼场景、清单、截止配送日提醒 |
| 季节性混合 | 分层发送，不同人群不同节奏 | 见冷温热分层思路 |

礼物类目注意：一年只触达 2–3 次（节前），频率过高换来的是退订——**复购稀疏的品类，EDM 的价值在获客成本的分摊（老客带回）而非复购本身**。

## 七、与社媒协同：同一套用户证据，两种表达

社媒四线内容（与 EDM 共享素材库）：

1. **真实场景演示**（用户怎么用）
2. **产品知识与误区**（参数、兼容、常见错误）
3. **用户故事**（UGC、评价、案例）
4. **售后与安全教育**（信任资产）

- 社媒的高频问题**回流**到 EDM（欢迎第二封、FAQ）；
- EDM 的长内容**改编**成社媒短内容；
- 平台选择看受众与团队产能，不为全渠道而全渠道：Instagram 适合生活方式与短视频，YouTube 适合深度测评与搜索长尾，TikTok 适合简洁场景切入，Pinterest 适合清单灵感；
- **每月一次内容资产盘点**：哪些视频能剪成广告、哪些评论变 FAQ、哪些测评可授权引用、哪些客户问题该反馈产品。

## 八、隐私与合规底线

- **名单不购买**；结账时未同意营销的用户不导入促销群发；
- 遵守退订机制、同意规则、跨境隐私要求（按适用地区核实，本文不构成法律意见）；
- 获客成本高，更不能把客户信息用于未经授权的再营销——一次违规的代价远超一个邮件列表的价值。

## 九、过关标准

- 三条自动化（欢迎/弃购/购买后）上线并跑过至少一个完整购买周期；
- 弃购流程不含"无条件自动折扣"；
- 能回答：哪个分组的邮件带来了净收入、退订率多少、每封邮件减少了多少客服工单。
