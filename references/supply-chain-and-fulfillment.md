# 供应链与履约：放大期的门票，选品阶段就要核验

> 供应链弱的站，流量越强，天花板压得越低。这句话值一个失败项目的全部学费。

## 一、选品阶段的一票否决项

在打开建站工具之前，逐项核验（任何一项不过，换品，不硬上）：

| 否决项 | 核验内容 |
|---|---|
| **认证合规** | 目的国产品安全/无线电/能源要求；供应商给的认证 Logo 不能直接复制，同系列某型号通过 ≠ 全部 SKU 满足 |
| **运输限制** | 电池、液体、尖锐件、磁性件；包装体积重是否击穿运费；目的国是否可配送 |
| **退货可行性** | 大件/易碎品退货逆向物流成本；损坏如何处理；哪些地区明确不配送 |
| **体积重量比** | "售价 ÷ 体积重量"是否健康——**礼物/家居类第一杀手** |
| **交期与补件** | 工厂真实交期、最小起订量、补件能力、旺季产能 |
| **售后复杂度** | 是否需要本地客服语言与时区；故障升级机制 |

## 二、尾程物流：持续抽血的环节

尾程占比的警戒线（占售价）：

- **< 12%**：健康
- **12–18%**：可优化，需要持续盯（换仓、谈价、改包装、凑重）
- **> 18%**：结构性伤害——在 $100 客单价上，每一单的贡献利润被持续抽血，且**换仓谈价改包装能挤出的空间通常有限**

判断是否"规模不经济"：单量上去后，尾程占售价比例**有没有下降**。不下降 = 越大越紧，这是模型级问题，不是运营级问题。

## 三、礼物品类的四个结构性特征（其他一次性消费品同理）

| 特征 | 后果 |
|---|---|
| 季节性极强（Q4 占全年大头） | 库存与现金流的年度大考：备多了压死现金，备少了断货空跑广告 |
| 体积/重量不经济 | 尾程占比高，贡献利润被持续抽血 |
| 退货集中在节后 | 退货准备之外，节后回流再吃一轮利润 |
| 一次性消费为主 | LTV 起不来，每单都要重新买一次客户 |

**四条单独任何一条都活得下去；四条叠在一个中客单价、供应链弱的模型上，就是"能活、长不大"。**

## 四、轻库存打法的代价

轻库存、快周转：起步快、掉头快、现金压力小——但反过来：

- **没有供应链壁垒**：货随时能拿，别人也随时能拿；
- 量上来后，采购价谈不下来、交期抢不过、品质控不住；
- 爆款断货时广告空跑，节前不敢备货，品质波动带来差评，退货集中时客服崩——**前端的问题，根子都在后端。**

## 五、现金流比利润先死

- 广告费即时支出，回款 30–60 天；节庆备货提前垫款；
- 单量越冲，现金越紧——"贡献利润为正、现金流断裂"是独立站最常见的真实死法；
- 每月画现金曲线，标出：广告支出峰值、备货支出峰值、回款低谷。**最紧的那个月就是这个模型能承受的单量上限。**

## 六、放大期门前的压力测试（加预算前必做）

1. **库存**：爆量 3 倍时，交期、品质、现金哪个先断？
2. **尾程**：占售价比例随单量下降吗？不下降就是规模不经济。
3. **现金**：最紧的月份能否覆盖广告 + 备货 + 固定支出？
4. **售后**：爆量后工单量、退货率、差评率是否可控？
5. **复购**：一次性消费品类，要么按现金流生意做（不追求规模），要么改造复购（耗材、配件、节日周期、会员体系）——**最怕假装它是个能积累用户资产的生意。**

三者有一个不过，停在门口修，不硬闯。

## 七、供应链弱的补救路径（按代价排序）

1. 换对供应链要求低的品类（轻、小、不易碎、无保质期）；
2. 与工厂谈深度合作（包销/独款/专供色），把"随时能拿的货"变成"只有你能拿的货"；
3. 改包装与组合装，把体积重量比救回来；
4. 海外仓 + 本地退换，把尾程和退货一次解决（需要单量门槛）；
5. 提客单价，用定价权覆盖履约成本——注意：提价通常掉转化，先小流量测试。
